UC-01 Cap nhat vi tri GPSTai xe, He thong (10s)Tai xe gui toa do GPS hien tai len server, cap nhat vi tri trong DB phan tanTai xe da dang nhap, is_available=true, co quyen GPS1. Mobile lay toa do GPS (moi 10s)
2. PATCH /drivers/location {driver_id,lat,lng}
3. Backend xac dinh region tu lat (>=16.5 NORTH)
4. queryWithFailover UPDATE drivers SET lat,lng,region
5. Tra ve driver object + region_routed_to		A1: GPS khong kha dung - dung mockLoc neu co
A2: Primary DB down - throw error, log warning
A3: driver_id khong ton tai - NotFoundException		Vi tri tai xe cap nhat trong DB, khach hang co the thay tren ban do
UC-02 Bat/tat trang thaiTai xeTai xe bat/tat toggle thong bao san sang nhan chuyen hoac nghiTai xe da dang nhap, co driver profile trong DB1. Tai xe nhan Switch toggle
2. PATCH /drivers/availability {driver_id,is_available,region}
3. Backend tim region (dto.region hoac findDriverRegion())
4. UPDATE drivers SET is_available
5. Neu bat: startLocationTracking()
6. Neu tat: stopLocationTracking(), stopPollingTrips()		A1: Khong tim thay driver - NotFoundException, revert toggle
A2: GPS permission denied - setIsAvailable(false)
A3: Network error - revert toggle, Alert loi		is_available cap nhat trong DB; GPS tracking va polling trips bat dau/dung

2. Goi reverseGeocode(lat,lng) - Nominatim API
3. Hien thi dia chi, toa do, thoi gian cap nhat
4. Tu dong cap nhat moi 10 giay		A1: Nominatim API loi - hien thi toa do tho [lat,lng]
A2: mockLoc duoc set - dung mockLoc thay GPS that		Tai xe thay vi tri hien tai, dia chi cap nhat lien tuc
UC-04 Xem thong tin tai xeTai xe, Khach hang, AdminLay thong tin chi tiet tai xe (bien so, loai xe, rating, so chuyen) tu DBUser da dang nhap (JWT hop le)1. GET /drivers/by-user/:userId?region=NORTH|SOUTH
2. Backend thu region chi dinh truoc, neu khong co thu region kia
3. SELECT * FROM drivers WHERE user_id=
4. Tra ve danh sach driver records		A1: Khong tim thay o ca 2 region - tra ve []
A2: GET /drivers/:id - tim theo UUID, fallback region kia		Thong tin tai xe hien thi tren UI (bien so, loai xe, rating)
UC-05 Gui tin nhanTai xe, Khach hangGui tin nhan text real-time qua WebSocket den nguoi dung trong cung chuyen xeUser da ket noi WS /chat, da join phong trip:id, chuyen xe dang active1. User nhap text, nhan nut Gui
2. Socket emit message:send {trip_id,receiver_id,content,type}
3. Gateway xac thuc senderId tu connectedUsers map
4. MessagesService.sendMessage() - getTripRegion() - INSERT INTO messages
5. Broadcast message:receive den room trip:id
6. Tra ve {event:message:sent, data:message}		A1: Chua xac thuc - WsException
A2: Primary DB down - WsException khong the gui
A3: readOnly=true - UI disable input		Tin nhan luu vao DB, broadcast den tat ca thanh vien phong chat
UC-06 Nhan tin nhanTai xe, Khach hang, He thongNhan tin nhan real-time tu nguoi dung khac trong cung chuyen xe qua WebSocketUser da ket noi WebSocket, da join phong trip:id1. Server broadcast message:receive den room
2. Client nhan event, kiem tra duplicate (msg.id)
3. Them tin nhan vao danh sach, scroll xuong cuoi
4. Neu la receiver - emit message:read		A1: Duplicate message (cung id) - bo qua
A2: WebSocket disconnect - setIsConnected(false), reconnect tu dong		Tin nhan hien thi tren UI, trang thai da doc cap nhat
UC-07 Danh dau da docTai xe, Khach hang, He thongDanh dau tat ca tin nhan chua doc trong chuyen la da docUser da ket noi WebSocket, dang trong phong chat1. Client emit message:read {trip_id} khi vao phong hoac nhan tin
2. Gateway goi MessagesService.markAsRead(trip_id, userId)
3. UPDATE messages SET is_read=true WHERE trip_id= AND receiver_id=
4. Broadcast message:read {trip_id,read_by,updated_count} den room
5. Sender nhan event - cap nhat is_read=true tren UI (vv)		A1: Chua xac thuc - WsException
A2: Primary DB down - loi, khong cap nhat duoc		Tin nhan danh dau da doc trong DB, UI hien thi vv
UC-08 Typing indicatorTai xe, Khach hangHien thi thong bao dang go... khi nguoi dung dang nhap tin nhanUser da ket noi WebSocket, dang trong phong chat1. User bat dau go - emit typing {trip_id, is_typing:true}
2. Gateway broadcast den nhung nguoi khac trong room (client.to(room))
3. Receiver hien thi {name} dang go...
4. Sau 2 giay khong go - emit typing {is_typing:false}
5. Receiver an typing indicator		A1: User chua xac thuc - return (khong throw)
A2: User gui tin - tu dong emit is_typing:false		Typing indicator hien thi/an real-time cho nguoi nhan
UC-09 Xem lich su chatTai xe, Khach hangTai lich su tin nhan cua mot chuyen xe tu DB khi mo man hinh chatUser da dang nhap, chuyen xe ton tai1. Mo ChatScreen - GET /messages/:trip_id
2. MessagesService.getTripRegion() - xac dinh DB region
3. SELECT m.*, u_sender.name, u_receiver.name FROM messages JOIN users
4. Tra ve {data:Message[], total, readOnly}
5. Hien thi danh sach tin nhan, scroll xuong cuoi		A1: Primary down - fallback replica, readOnly=true
A2: Trip khong ton tai - tra ve []
A3: readOnly=true - hien thi warning banner, disable input		Lich su chat hien thi day du, trang thai readOnly phan anh tren UI
UC-10 Tim tai xe lan canKhach hang, He thongTim danh sach tai xe dang san sang trong ban kinh nhat dinh tu vi tri khachKhach hang co toa do GPS, co it nhat 1 tai xe online trong khu vuc1. GET /drivers/nearby?lat=&lng=&radius_km=&vehicle_type=
2. Backend xac dinh region tu lat
3. Dung earthdistance: earth_box + earth_distance
4. SELECT drivers WHERE is_available=true AND vehicle_type= AND trong ban kinh
5. ORDER BY distance_km ASC, rating DESC LIMIT 10
6. Tra ve {metadata:{region,is_read_only_fallback,total_found}, data:drivers[]}		A1: Primary down - fallback replica (isReadOnly=true), van tra ket qua
A2: Khong co tai xe trong ban kinh - data:[], total_found:0
A3: radius_km > 50 - validation error		Danh sach tai xe lan can duoc tra ve, khach hang co the chon dat xe
