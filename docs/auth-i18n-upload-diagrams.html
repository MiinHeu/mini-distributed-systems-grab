Auth + Da ngon ngu + Upload anh - Diagrams

Source snapshot: 2026-05-11

Scope

These diagrams describe the current auth, language selection, and avatar upload flows in the repo. Use them as a reference when updating code later.

Current upload storage is local (/uploads/avatars) and avatar_url is relative (/uploads/avatars/..). If switching to Cloudinary, replace the storage participant and avatar_url becomes absolute.

Use Case Diagram

Sequence Diagram - Login

sequenceDiagram actor User participant Client as Web/Mobile App participant API as Backend API (NestJS) participant DB as Postgres (users) User->>Client: Enter email/password Client->>API: POST /auth/login (Accept-Language) API->>DB: SELECT user by email DB-->>API: user + password hash API->>API: bcrypt compare + JWT sign API-->>Client: { token, user, message } Client-->>User: show message

Sequence Diagram - Update Language

sequenceDiagram actor User participant Client as Web/Mobile App participant API as Backend API (NestJS) participant DB as Postgres (users) User->>Client: Change language (vi/en) Client->>Client: changeLanguage + update local UI alt user logged in Client->>API: PATCH /auth/me { preferred_language } API->>DB: UPDATE users.preferred_language DB-->>API: updated user API-->>Client: user (message by Accept-Language) Client-->>User: UI in selected language else not logged in Client-->>User: UI language only (no server update) end

Sequence Diagram - Upload Avatar (Local Storage)

sequenceDiagram actor User participant Client as Web/Mobile App participant API as Backend API (NestJS) participant Storage as Local Uploads (/uploads/avatars) participant DB as Postgres (users) User->>Client: Pick image Client->>API: POST /auth/me/avatar (multipart + Bearer) API->>API: JwtAuthGuard verify token API->>Storage: Save file via multer diskStorage API->>DB: UPDATE users.avatar_url DB-->>API: updated user API-->>Client: { message, user } Client-->>User: show avatar (API_BASE_URL + avatar_url)
